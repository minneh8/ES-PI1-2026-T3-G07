**Descrição do projeto**

Este projeto é um sistema de votação desenvolvido em Python com integração a banco de dados MySQL.
O sistema permite o cadastro de eleitores, registro de votos e apuração dos resultados.
Além disso, para aumentar a segurança dos dados, é utilizada criptografia (Cifra de Hill) para proteger informações sensíveis como o título eleitoral/CPF.

**Tecnologias Utilizadas**

--> Python 

--> MySQL (Uso do MySQL Workbench 8.0)

--> Biblioteca mysql-connector-python

--> Biblioteca Random

--> Biblioteca Numpy

--> Algoritmo de criptografia (Cifra de Hill)

--> GitHub

--> Documentação em DocString

**Funcionalidades**

--> Cadastro de eleitores

--> Autenticação de eleitor

--> Registro de voto

--> Criptografia de dados sensíveis

--> Apuração de resultados

**Instruções Para Uso**

--> Abra o MySQL Workbench 8.0

--> Execute o arquivo .sql que está disponível no repositório do GitHub para criar o banco de dados e suas tabelas

--> Abra o projeto em uma IDE (recomendado: VS Code)

--> Certifique-se de que as bibliotecas estejam instaladas

--> Ajuste a senha de acesso ao servidor do MySQL Workbench se necessário

--> Execute o arquivo principal do sistema (menu_principal.py)

--> Cadastre seus eleitores

--> Cadastre seus mesários

--> Vote!
